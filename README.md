## 📌 Overview

This repository contains the source code for the personal portfolio of **Swapnil Tole**, a **Java Full-Stack Developer**. The website showcases skills, professional experience, academic background, featured projects, and contact avenues through interactive 3D elements, sleek glassmorphism styling, and fluid motion animations.

---

## ✨ Key Features

- 🎥 **Cinematic Video & Hero Section**: Dynamic introduction featuring video reels and smooth typography reveals.
- 🎨 **Modern Aesthetics & Glassmorphism**: Polished dark-mode theme with glassmorphic cards and subtle gradient glows.
- ⚡ **Interactive 3D & GSAP Animations**: High-fps interactive animations powered by Three.js and GreenSock (GSAP).
- 💻 **Interactive Tech Stack Showcase**: Categorized badges highlighting expertise in frontend, backend, databases, and DevOps tools.
- 📂 **Featured Projects Showcase**: Grid view of production-grade and personal projects with live demo and GitHub repository links.
- 💼 **Experience & Education Timeline**: Structured timeline presenting career progression and academic milestones.
- 📨 **Interactive Contact Modal**: Functional contact form and direct mail links for recruiter inquiries.
- 📱 **Fully Responsive**: Flawless experience optimized across mobile, tablet, laptop, and ultra-wide displays.
- ⚡ **Blazing Fast**: Powered by Vite with near-instant hot module replacement (HMR) and optimized production bundles.

## 🚀 Getting Started

Follow these steps to run the portfolio locally on your machine:

### 1. Prerequisites
Ensure you have **Node.js** (version 18 or later) installed.
- Check Node version: `node -v`
- Check npm version: `npm -v`

### 2. Clone the Repository
```bash
git clone https://github.com/SwapnilTole182/swapnil-portfolio.git
cd swapnil-portfolio
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Run Development Server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

### 5. Build for Production
```bash
npm run build
```
The optimized production output will be generated in the `dist/` folder.

### 6. Preview Production Build
```bash
npm run preview
```
